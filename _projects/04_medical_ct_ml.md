## Overview

A medical CT image-analysis project using the publicly available **COVID-CT-MD** dataset in DICOM format.

## Key contributions

- Developed a workflow for DICOM preprocessing, segmentation, and quantitative feature extraction.
- Compared multiple segmentation approaches.
- Extracted texture, shape, and intensity-distribution features.
- Implemented and evaluated **Random Forest, SVC, and KNN** classifiers for COVID-19, community-acquired pneumonia, and normal cases.
- Used cross-validation and standard classification metrics for evaluation.
